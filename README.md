Israel Client 1.8.9 
Actively updated free and open source 1.8.9 minecraft utility client

Includes bypasses for anticheats such as: Hypixel, Grim, Intave, Matrix, Vulcan, Verus and More!

This Client is based off of Myau 

Discord server: https://discord.gg/sfkTwtp3F


Installation:
1. Install Minecraft with  Forge 1.8.9
2. Install the jar from the releases section
3. place it in your mods folder and launch
4. Have Fun!
